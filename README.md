# Kart Game Takeover

**skatebird** × Kart Game · visual · idea by the team

Bring Kart Game into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> I turned SkateBIRD into a kart race: a cloud marshal, rival drivers, item boxes and a bird whose kickflips fuel the turbo. Bananas are mean.

## Install

Install BepInEx 5 (64-bit) into your SkateBIRD folder, then copy the SigfMix folder from the release into BepInEx/plugins and start the game. The race begins by itself on the playground: drive through rainbow boxes for items, and press E to use one early.
